# Política de Segurança

## 1. Reporte de Vulnerabilidades

Caso você identifique alguma vulnerabilidade neste projeto ou organização, reporte imediatamente para: security@acme.com.br (e-mail fictício). Operamos em regime de divulgação responsável.

## 2. Boas Práticas

- Nunca exponha dados sensíveis em código público.
- Faça revisões periódicas de dependências.
- Use ferramentas automáticas para scanner de vulnerabilidades.

## 3. Autenticação

- É obrigatório o uso de 2FA (autenticação de dois fatores) para todos os colaboradores.
