# Guia de Contribuição — acmeorg

## 1. Como contribuir

1. Faça um fork deste repositório.
2. Crie uma branch descritiva a partir de `main`.
3. Siga a política de commits: `feat:`, `fix:`, `docs:`, `refactor:`, `test:`, `chore:`.
4. Envie um Pull Request detalhando suas alterações.
5. Aguarde revisão, siga as orientações dos revisores e corrija os pontos levantados, se necessário.

## 2. Padrões de Código
- Utilize padronização definida por `eslint`, `prettier` ou arquivo próprio.
- Cobertura de testes obrigatória para novas funcionalidades.
- Nomes de funções, arquivos e variáveis devem ser claros e seguir o padrão camelCase/Snake_case conforme tecnologia.

## 3. Comunicação
- Problemas e dúvidas: abra ou comente em Issues.
- Use os modelos de issues e pull requests disponíveis.

## 4. Conduta
- Respeite o [Código de Conduta](./CODE_OF_CONDUCT.md).
