# Manual de Suporte — acmeorg

## 1. Canais de Suporte

- Priorize o uso de Issues para reporte de erros ou problemas técnicos.
- Dúvidas gerais serão respondidas via Discussions ou via e-mail: suporte@acme.com.br.

## 2. Tempo de Resposta

- Prazo de resposta: até 72h úteis.
- Incidentes de segurança recebem prioridade máxima.

## 3. Antes de abrir um chamado

- Verifique no README e Issues abertas se sua dúvida já não foi respondida.
